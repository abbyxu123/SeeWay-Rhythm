# 时家奇门四类提示规则索引

日期：2026-08-28

状态：V1 第一批规则，限日常通用层；不用于金融、医疗或针对具体问事的判断。

## 1. 固定口径

- 主体系：`qimen-zhuanpan-chaibu-v1`，只接受通过独立校验器的完整时家转盘。
- 提示规则版本：`qimen-gate-baseline/v1`。
- 主依据：《奇门遁甲入门教程-神奇之门》张志春。
- 文件指纹：`sha256:507852339d4205bee3ab7f9b009888e77c551bfb1ff0c627d0a07a7b01c4a96f`。
- 页码约定：同时记录书内印刷页和 PDF 页，避免扫描版页码偏移造成误读。
- 输出范围：有利、注意、方位、建议，以及证据编号和不确定性。

书中印刷页 111 明确指出，开、休、生通常归为三吉门，死、惊、伤通常归为三凶门，杜、景为中平；同页也明确提醒实际使用还必须结合门所临宫位及旺相休囚。因此本批规则只能形成“八门基础倾向”，不产生“最终吉凶”或“绝对宜忌”。

## 3. 方位解释

方位来自八门在当前盘中的实际落宫，而不是八门的先天固定宫位。每条方位必须同时保存：

- 宫号和八方方向。
- 该宫实际所临八门。
- `supportive` 或 `avoid`，不可只写“吉方”“凶方”。
- 对应规则 ID 和证据 ID。

开、休、生落宫只表达其适合事项的支持方向；伤、死、惊落宫只表达日常一般事项的慎用方向。杜、景缺少具体问事时保持情境性，不为了填满界面强行归入支持或慎用。

## 4. 冲突策略

1. 未通过 `qimen-verifier/v1`，或不是计算器本次真实生成的盘，直接返回 `insufficient`，四类内容全部为空。
2. 同一输出槽出现不同结论时，先比较规则强度；较强证据成为主结论，并记录冲突。
3. 同强度且方向相反时，不选择任意一边，删除该槽结论并记录 `unresolved`。
4. 不同输出槽可以并存，例如整体值使门偏有利，同时仍保留其他宫位的慎用方向。
5. 本批规则尚未实现门宫五行生克、旺相休囚、格局克应、空亡强弱、马星动象和具体问事用神，所以只要有规则命中，不确定性固定为 `partial`。

## 5. 屏幕文本边界

- 文本是对规则效果的短句归纳，不复制大段书中文字。
- 不输出“必然”“一定”“灾祸”等确定性措辞。
- 不从姓名、情绪或语言模型联想补充吉凶。
- 金融奇门使用独立规则集、行情输入和回测结果，不复用本规则集冒充金融信号。
