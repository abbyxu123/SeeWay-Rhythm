# 排盘口径决策表

日期：2026-08-21

状态：V1 奇门主体系已选定；排盘各层按实现与验证进度逐项开放

术数程序最容易出现的错误不是代码写不出来，而是把不同流派的前提悄悄混在一起。本表是计算器的启用门：未形成版本化决定的项目，不进入正式结论。

## 通用时间口径

| 决策 ID | 项目 | 必须明确的内容 | 当前状态 |
| --- | --- | --- | --- |
| `TIME-001` | 输入历法 | 公历、农历及闰月如何声明与转换 | 待确认 |
| `TIME-002` | 出生时间 | 民用钟表时、真太阳时或双口径比较 | 待确认 |
| `TIME-003` | 时间精度 | 精确分钟、时辰范围或未知时间如何降级 | 待确认 |
| `TIME-004` | 时区 | 出生地历史时区、夏令时和目标地时区 | 待确认 |
| `TIME-005` | 子时换日 | 23:00 或 00:00 换日，是否区分早晚子时 | 待确认 |
| `TIME-006` | 节气边界 | 数据源、计算精度和恰逢交节点的归属 | 待确认 |

系统必须同时保存用户输入值、输入类型、时区和精度。请求边界只接受有效 IANA 时区标识；历史时区和夏令时采用哪一个数据源仍需按 `TIME-004` 锁定。若未来支持真太阳时，原始民用时间与换算结果都要保留，不能覆盖原值。

## 奇门口径

| 决策 ID | 项目 | 必须明确的内容 | 当前状态 |
| --- | --- | --- | --- |
| `QIMEN-001` | 主体系 | 转盘或飞盘、拆补或置闰等主版本 | 已锁定：V1 采用时家转盘与拆补法，不混用置闰法 |
| `QIMEN-002` | 阴阳遁与局数 | 节气、上中下元和局数算法 | 来源口径已锁定；计算器与边界测试待实现 |
| `QIMEN-003` | 排布顺序 | 地盘、天盘、九星、八门、八神的落宫规则 | 来源口径与三个完整盘例已锁定；计算器待实现 |
| `QIMEN-004` | 空亡与马星 | 算法、作用范围和强弱表达 | 盘面事实口径已锁定；断法强弱仍待规则层确认 |
| `QIMEN-005` | 时辰边界 | 每两个小时的归属及子时特殊处理 | 已锁定：复用 `time-core` 民用时十二时辰边界 |
| `QIMEN-006` | 用神优先级 | 年命、日干、时干及各专题用神的关系 | 待确认 |
| `QIMEN-007` | 方向解释 | 宫位方向、出发地、目的地和行动类型 | 待确认 |
| `QIMEN-008` | 规则冲突 | 格局、门星神仪之间的优先级与抵消条件 | 待确认 |

首个实现目标是一个单一、可说明的主体系。其他流派只能作为带版本的独立算法配置或研究对照，不能在同一报告中无标注混用。

### V1 奇门决定记录

- 算法版本：`qimen-zhuanpan-chaibu-v1`。
- 主规则来源：《奇门遁甲入门教程-神奇之门》张志春，文件指纹与核读范围见[资料分级与使用台账](./source-catalog.md)。
- 完整盘例来源：河北周易研究会奇门遁甲高级班笔记。
- 已核验案例：阳遁四局、阳遁九局、阴遁五局，共三个不同遁局组合，均包含九宫、九星、八门、八神、天地盘干、值符值使、旬首、空亡与马星。
- 替代口径：飞盘、置闰、日家、月家及其他断法体系均不进入此版本；未来只能以新算法版本和独立黄金案例启用。
- 当前影响：黄金案例只打开“可以开发计算器”的门，不使任何奇门 Agent 自动变为可用。计算器、独立校验器与规则层仍须分别通过测试。

## 决策通过标准

每一项从“待确认”改为“已锁定”时，必须同时记录：

- 决定内容与生效版本。
- 采用该口径的来源索引和必要说明。
- 被排除的常见替代口径及原因。
- 至少一个正常金样和一个边界金样。
- 对现有历史快照和 Agent 版本的影响。

参考书只能帮助形成候选规则。能够被程序稳定执行、被人工逐层核对，才算进入生产规则。
