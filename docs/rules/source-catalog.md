# 奇门资料分级与使用台账

日期：2026-08-26

状态：持续维护；本文件只决定资料能否进入哪一层，不代表相关规则已经实现。

## 1. 判断标准

本项目不把“古籍”“名家”或“案例很多”直接等同于可用于程序。每份资料按以下顺序检查：

1. 能否确认其奇门体系、起局法与适用时间尺度。
2. 是否与 V1 的转盘、时家、拆补、节气定局口径一致。
3. 规则能否写成明确输入、条件、中间事实和输出，而不是只靠临场类比。
4. 是否有日期、干支、局数和九宫信息完整的盘例可逐宫复核。
5. 同一规则是否能找到反例、边界例或第二来源交叉检查。

“准确”在这里表示排盘过程、版本和来源可以复现，不表示术数结论已经得到现代科学验证。

## 2. 分级定义

| 等级 | 用途 | 进入程序的条件 |
| --- | --- | --- |
| A 主依据 | V1 排盘规则和黄金案例 | 体系一致、规则明确、至少有完整盘例 |
| B 交叉校验 | 检查古法出处、术语和规则差异 | 只能确认或提出差异，不能静默覆盖 A 级规则 |
| C 独立体系 | 日家、月家等不同时间尺度 | 独立模块、独立版本、独立黄金案例 |
| D 研究假设 | 金融专题、经验断法 | 先结构化和回测，不进入默认结论 |
| E 归档 | 当前范围外或风险较高的题材 | 不加载到生产 Agent |
| P 待评审 | 尚未完成体系识别与案例核验 | 不进入任何正式计算 |

## 4. 待评审资料

以下资料可能有用，但尚不能据此写生产规则：

- 《图解奇门遁甲大全》第 1-3 部：需确认其排盘口径、转载来源和 1080 局盘例的一致性。
- 《开悟之门》、案例集、答疑及其他课程资料：可继续补充用神、格局、冲突和断法规则。
- 河图洛书、梅花易数、紫微、八字资料：分别进入对应领域台账，不用于修正 `qimen-core` 盘面事实。

## 5. 进入代码的门槛

一条资料规则只有同时具备以下记录，才可进入正式规则库：

- `ruleId`、体系版本和适用 Agent。
- 精确来源指纹与页码或案例定位。
- 明确的前置条件、输入事实和输出，不依赖隐含常识。
- 命中、不命中、边界和冲突测试。
- 与排盘事实层分离；规则不能反向修改盘面。
- 至少一次人工复核；金融规则还必须有独立历史回看结果。

## 6. 当前结论

现有资料足够开始实现 V1 的时家转盘拆补排盘，不需要继续等待更多书。当前真正缺少的不是资料数量，而是把已选主体系逐层写成确定性算法，并用黄金案例和独立校验器验证。后续资料最有价值的方向，是补充同一体系的完整盘例、边界案例和可定位的断法规则。
